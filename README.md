**Double Take** — an original spot-the-difference game. Four hand-drawn scenes (all art drawn in code): Harbour Morning (5 differences, 90s), Forest Camp (6, 80s), Market Day (7, 70s), Orbital Station (8, 60s) — 26 differences total, difficulty rising per scene. Two near-identical pictures side by side, golden-ring markers on found differences, a counter of how many remain, countdown timer, hints, hearts, score and stars. Vanilla JS, no network requests, no vendored libraries.

## Play it

Serve `game/` with any static HTTP server and open `index.html` in desktop Chrome. Keyboard: H hint, R restart scene, M mute, Enter next.

## Hand it in

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Copies `game/` + `screenshots/` to the output directory and writes `dossier.json`.
